# Marketing UI

Marketing interfaces need a memorable point of view and a clear conversion
sequence. Boldness can mean maximal expression or severe restraint.

## Direction

- Commit to one aesthetic language; do not blend several fashionable styles.
- Let typography carry voice. Display type can be risky; body copy remains
  highly readable.
- Choose one dominant color world with one sharp accent.
- Vary composition and rhythm across sections while keeping a coherent system.
- Use imagery, texture, motion, and atmosphere only when they reinforce the
  story and product.

## Narrative

Every section needs a job:

1. establish the specific promise
2. make the mechanism understandable
3. prove credibility
4. resolve objections
5. make the next action unmistakable

Avoid the default hero → three feature cards → logo bar → testimonials →
pricing towers → centered CTA sequence unless the content genuinely demands
it.

## Anti-generic check

- Can someone describe the page from memory tomorrow?
- Does the hero composition differ from the common centered or left-copy/right-
  screenshot template?
- Is the visual signature repeated with enough restraint to become identity?
- Are typography, imagery, motion, and copy expressing the same tone?
- Would swapping in another company's name still work? If yes, the design is
  not specific enough.
